# Telegram Drive - Privacy Policy

This application is a personal tool used only by its owner. It receives files that the owner sends to a private Telegram bot and uploads them to the owner's own Google Drive, using the drive.file scope (access limited to files created by the app).

The application does not collect, sell, or share personal data with third parties. Files are processed temporarily on GitHub Actions runners and deleted when the job ends. Google OAuth credentials are stored only as encrypted secrets in a private repository.
